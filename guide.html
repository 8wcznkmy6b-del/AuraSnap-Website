AuraSnap 用户使用手册

本手册包含 AuraSnap 各项功能的使用说明、快捷键映射、文本与图像处理套件、偏好设置配置以及常用交互细节。

适用版本：v2.7.9 15 个功能模块 35+ 快捷键与手势 macOS 13.0+ / Apple Silicon
1. 屏幕截图与窗口探测 截屏基础

1.1 快捷键触发与自适应调光

  • 唤起截图：默认快捷键为 ⌥ + 1（Option + 1），可在偏好设置中重新录制。
  • 背景自适应明暗：按下快捷键后背景适度压暗以突出选区。当鼠标移动超过 3pt 时恢复屏幕原始亮度与色彩，拖拽生成选区后仅选区外保持暗色遮罩，确保框选与取色无色差。
  • 转场与防抖：采用统一转场度量（120ms），进出平滑淡入淡出；主线程加入防重入锁，避免高频连击导致重复创建窗口。

1.2 窗口与 UI 控件吸附

  • 窗口自动吸附：鼠标悬停在应用上方时自动识别并高亮当前窗口边界。
  • 宏观与微观吸附切换 (Space)：
    • 默认模式：吸附整个应用窗口。
    • 按下空格键：切换为吸附按钮、输入框、标签页等局部 UI 控件（基于系统辅助功能接口探测）。
  • 层级穿梭：悬停时滑动鼠标滚轮，可在父容器与子控件层级树之间上下切换探测目标。

1.3 取色器与放大镜

  • 差分十字标尺：十字线采用底片反色差分效果，在明暗背景下均清晰可见。
  • 21×21 像素放大镜：显示中心十字准星与当前光标处精确像素色值。
  • 复制色值：按 C 键将当前像素的 HEX 与 RGB 色值复制到剪贴板。
  • 像素微调：按方向键 ↑ ↓ ← → 以 1px 步进微调准星位置。
2. 屏幕贴图 (Pin Window) 贴图交互

2.1 基础操作与生命周期

  • 固定为贴图：选区完成后点击工具栏【贴图】按钮或按快捷键 ⌘ + P，窗口以浮动级别置顶显示。
  • 双击关闭：双击贴图空白处即可关闭当前贴图。
  • 中键重置：鼠标中键单击贴图，恢复 100% 原始缩放比例与不透明度。
  • 多贴图并发：支持同时固定多张贴图，每张贴图独立记忆缩放大小与位置。

2.2 拖拽外发与高级交互

📌
按住 Command 键直接拖拽外发 在贴图上按住 ⌘ 键并拖拽，可直接将图片拖入微信、钉钉、飞书、Slack、邮件等聊天输入框发送，或直接拖入访达文件夹保存为 PNG 文件。
  • 缩放与精度保持：支持触控板双指捏合或滚轮无级缩放（0.3x ~ 10x），内部使用浮点坐标追踪，避免缩放过程中的像素累计漂移。
  • 透明度调节：按住 ⌥ + 滚动滚轮，可在 10% ~ 100% 之间调节透明度。
  • 鼠标穿透模式 (Ghost Mode)：
    • 右键菜单或快捷键 ⌥ + G 开启穿透模式后，鼠标点击将直接穿透贴图操作底层网页或代码。
    • 穿透状态下长按 ⌥ 键可临时接管贴图进行拖动与调整。
  • 全域快捷键响应：贴图激活时支持 ⌘ + C（复制）、⌘ + S（保存）、⌘ + P（再转贴图）、Esc（关闭）。
  • 非破坏性二次标注：贴图自带悬浮工具栏，可随时追加画笔、矩形、马赛克等标注，支持 ⌘ + Z 撤销。
  • 误关恢复 (⌥ + 2)：贴图关闭时暂存于磁盘缓存，按 ⌥ + 2 可按后进先出顺序依次恢复已关闭的贴图。
3. 剪贴板内容转贴图 (Text/Image-to-Pin) 剪贴板直出

3.1 一键生成贴图 (⌘ + ⌥ + T)

复制任意文本、代码、JSON 或外部图片后，按快捷键 ⌘ + ⌥ + T 即可直接在当前屏幕中央生成浮动贴图，省去保存或手动截图步骤。

  • 文本/代码贴图：自动采用毛玻璃背景与等宽排版展示文本内容。
  • 外部图片贴图：自动裁切边缘透明留白（Alpha Trimming），并根据屏幕尺寸自动缩放居中。
  • 空白处穿透拖拽：文本贴图在行间或空白区域点击可直接拖拽移动，文字区域保留高亮划选能力。
  • 文本截断保护：对超长文本（上万像素）提供底部渐变截断保护，确保性能平稳。
4. 区域录屏与动图导出 录屏导出

4.1 导出格式支持

MP4 视频
基于 Apple 原生硬件加速编码，色彩保真度高，适合较长时长的操作演示与归档。
GIF 动图
内置动态调色板量化算法，减少色彩断层，适合聊天工具快速分享与短演示。
WebM 格式
采用 VP9 编码，在保持高清画质的同时显著缩减文件体积。

4.2 预览与拖拽外发

  • 录完即览：录制完成后弹出循环播放预览面板。
  • 按住 ⌘ 拖拽分享：在播放器内按住 ⌘ 拖拽，可直接将视频或 GIF 拖入聊天软件发送，或拖至访达保存。
  • GIF 剪贴板原生支持：按 ⌘ + C 复制动图时写入标准 GIF 二进制数据流，粘贴到聊天软件直接显示为动图。
5. 滚动截长图 (Long Screenshot) 长图拼接

5.1 图像拼接机制

  • 自适应拼接检测：慢速滚动时使用二维动态规划接缝切取算法，快速滚动时使用滑窗匹配，自动识别重叠区域进行无缝拼接。
  • 图层穿透抓取：直接捕获物理底图，消除长截图启动与完成时的画面闪烁。
  • 末帧同步：点击完成前强制刷新图层状态，避免最后一行内容遗漏。

5.2 微缩地图与交互

  • Retina 微缩地图：右侧提供 160pt 宽度的实时缩略图，随滚动自顶向下扩展预览。
  • 滚动条与微调：支持拖拽滚动条翻页；按住 Shift 键拖拽可开启 1/4 阻尼慢速微调模式。
  • 快捷键操作：长截图预览状态下支持 ⌘ + C（复制）、⌘ + S（保存）、⌘ + P（转贴图）。
6. OCR 文字识别与文本清洗套件 OCR Studio

6.1 触发与操作方式

  • 快捷键直达：按 ⌥ + 4 框选任意区域，松开鼠标直接弹出 OCR 结果面板。
  • 工具栏/贴图提取：截图或贴图时点击工具栏 🔍 图标或按 ⌥ + O 提取文字。
  • 图片拖拽识别：将本地图片文件（PNG、JPG、WebP、HEIC 等）直接拖入 OCR 窗口，自动执行识别并更新文本。
  • 连续追加模式：开启 Header 栏「追加模式」后，多次连续截图的识别文字将自动换行拼接在文末，适合整理多页文档。

6.2 空间排版与表格还原

  • 阅读顺序还原：根据行高垂直聚类与水平间距，还原多栏排版与表格行列对齐结构。
  • 转 Markdown 表格：按制表符或间距智能分列，一键转换为标准 GitHub Flavored Markdown 表格，可直接粘贴至 Obsidian、Notion 等工具。

6.3 快捷文本清洗工具栏

OCR 面板顶部集成快捷格式化工具栏，支持对全文或局部选中文本执行清洗：

清洗 ▾
排版 ▾
大小写 ▾
标点 ▾
✨ AI 解释
1. 「清洗」菜单
• 智能去空格：仅在英文字词之间或英文与数字之间保留必要词距空格，清除汉字、标点及括号周围的冗余空格。
• 去换行：合并段落内的断行，并自动拼接行尾英文连字符（如 connec- + tion → connection）。
• 清理空行：移除连续的空白行。
2. 「排版」菜单
• 智能间距 (Pangu)：在中文字符与英文单词、数字之间自动插入规范空格。
• 转 Markdown 表格：将表格文本自动转换为标准 Markdown 表格语法。
3. 「大小写」菜单
• 全部大写 (UPPERCASE)
• 全部小写 (lowercase)
• 首字母大写 (Title Case)
4. 「标点」菜单
• 标点转半角：将中文全角标点符号（，。！？（））转换为标准 ASCII 半角标点。
• 局部清洗感知：选中局部文字时，所有格式化操作仅作用于所选范围。

6.4 二维码检测、AI 解析与快捷操作

  • 二维码/条形码识别：自动检测画面中的二维码与条码，顶部滑出横幅提供一键【打开网址】或【复制内容】。
  • AI 流式解析：点击「✨ AI 解释」调用大模型进行内容提炼，支持思考过程折叠、Markdown 渲染与多轮连续追问。
  • 复制并关闭：按快捷键 ⌘ + ↩（Command + Return）一键复制当前文本并关闭 OCR 窗口。
7. 标注工具与智能图形 矢量标注

7.1 常用标注工具

  • 基础图形：矩形、椭圆、箭头、直线、折线。
  • 自由画笔与荧光笔：贝塞尔曲线平滑绘制，支持半透明叠色。
  • 马赛克与高斯模糊：提供像素化马赛克与平滑高斯模糊两种模式。

7.2 引线批注 (Remark)

  • 锚点与卡片联动：第一点锁定目标位置，第二点放置说明卡片。
  • 边缘自动吸附：移动卡片时，引线根据几何相交算法自动停靠至卡片四边最优位置，支持直线与直角折线两种风格。
  • 打字自适应扩展：输入文字时卡片宽度与引线交点平滑向外延展，避免遮挡内容。

7.3 步骤序号图钉与手绘矫正

  • 水滴指向图钉：带尖端锚点，支持绕尖端 360° 旋转指向特定控件；删除任意序号后，后续编号自动递补（如删除 2 号，原 3、4 自动变为 2、3）。
  • 手绘图形自矫正：随手绘制圆圈、矩形或折线时，自动矫正为规则几何图形。
  • 敏感信息脱敏：一键识别画面中的手机号、身份证号、银行卡号及人脸并添加马赛克。
8. 防泄密平铺水印 安全滤镜
  • 底层滤镜覆盖：水印作为底层全局滤镜铺满截图区域，在此之上添加箭头、框选或文字标注时不会误选或移动水印。
  • 参数调节：支持 0° (水平)、45° (向右下)、-45° (向右上) 三种预设角度切换，并可通过滑块调节平铺疏密程度。
  • 导出全链路保持：保存图片、复制剪贴板、固定贴图与长截图均同步合成水印层。
9. 图像抠图与主体提取 主体提取
1. 拉普拉斯高频净底
适用于纯色背景、代码截图、图标与 App 卡片。基于高频能量微分，保持文字边缘锐利与反锯齿，消除白边。
2. 云端商业级去背 (Bria API)
适用于人像、宠物毛发与半透明物体。支持配置自有 API 密钥，生成高质量连续透明通道。
3. Apple Vision 离线兜底
调用系统原生前景分割接口，无需网络即可完成基础主体提取。

抠图后背景呈现透明棋盘格，支持原位切换（点击【抠图】原位去背，再次点击恢复原图背景），贴图右键支持【仅复制主体】导出透明 PNG。

10. AI 视觉大模型集成 AI 助手
  • 兼容协议端点：支持接入兼容 OpenAI 协议的各类服务（包括 SiliconFlow、OpenAI GPT-4o、Claude 3.5、DeepSeek-V3/R1、Google Gemini 及本地 Ollama），自由配置 Base URL 与 Key。
  • 不可见字符自动清洗：粘贴 API Key 或 URL 时，自动过滤剪贴板附带的零宽空格、双向控制符与非断行空格，避免配置格式报错。
  • 标注引导感知：如果在截图中用红圈或箭头圈出特定区域，系统 Prompt 会自动引导大模型重点分析被圈选的局部区域。
11. 外观与独立主题 主题配置
  • 分模块独立配置：「主工具栏」与「OCR 结果窗口」外观配置相互独立，可在偏好设置中分别设定。
  • 三种外观风格：
    • 通透玻璃 (Liquid Glass)：采用系统级毛玻璃材质与微暗调吸光滤镜，呈现半透明质感。
    • 高对比度 (HUD)：采用深色厚磨砂材质，吸收浅色高光反光，提升大段文字阅读对比度。
    • 经典纯色 (Classic)：跟随系统深浅模式的纯色底板。
12. 菜单栏与工具栏定制 自定义布局
  • 菜单栏功能排序：偏好设置支持对系统状态栏菜单项进行显隐勾选与上下拖拽排序。
  • 直达模式：点击菜单栏「文字识别」或按 ⌥ + 4，框选松手直接弹出识别结果；点击「录制动图」或「滚动截长图」直接进入录屏/长图状态。
  • 工具栏独立配置：提供【截图工具栏】与【贴图工具栏】两套独立配置，支持单个工具显隐开关与拖拽重排；工具栏支持跨屏幕自由拖拽并记忆位置。
13. 快捷键配置 快捷键

13.1 全局快捷键

  • 屏幕截图：默认 ⌥ + 1
  • 恢复贴图栈：默认 ⌥ + 2
  • 历史图库：默认 ⌥ + 3
  • 文字识别直达：默认 ⌥ + 4
  • 剪贴板转贴图：默认 ⌘ + ⌥ + T
  • 贴图穿透模式：默认 ⌥ + G

13.2 局部操作快捷键

  • 复制内容：⌘ + C（截图、贴图、动图均适用）
  • 保存文件：⌘ + S
  • 固定贴图：⌘ + P
  • 执行 OCR：⌥ + O
  • OCR 复制并关闭：⌘ + ↩
  • 复制取色：C
  • 撤销 / 重做：⌘ + Z / ⇧ + ⌘ + Z
  • 退出 / 取消：Esc 或 单击右键
14. 历史记录与离线搜索 历史管理
  • 图库浏览：查看历史截图，支持设置保留周期（1天 / 3天 / 7天 / 永久），过期自动清理。
  • 本地离线文字检索：截图在本地提取文本索引，在搜索框输入关键词即可查找包含对应文字的历史截图。
  • 按需加载：采用磁盘缓存与按需加载机制，避免内存过度常驻。
