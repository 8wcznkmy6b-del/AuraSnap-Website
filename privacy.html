隐私政策

适用于 AuraSnap 客户端、AuraCleaner 与本网站。简单说：你的截图和剪贴板内容留在你的 Mac 上。

1. 原则

AuraSnap 由独立开发者 Dochi 开发和运营。截图、文字识别和剪贴板历史可能包含你最敏感的信息，所以我们的做法是：能在本机完成的都在本机完成，不收集与功能无关的数据，不做用户画像，不投放广告。

2. 在本机处理、不会上传的内容

  • 截图、长截图、录屏：只保存在内存和你选择的位置，不会上传到我们的服务器。
  • 文字识别：使用 macOS 自带的识别能力，在本机离线完成。
  • 系统翻译：使用 macOS 自带的离线翻译，在本机完成。
  • 剪贴板历史：保存在本机 AuraSnap 的数据目录中。被标记为敏感的内容（例如来自密码管理器）和你指定忽略的应用不会被记录。
  • 设置与使用记录：保存在本机。

3. 你主动使用时才会联网的功能

下列功能需要把内容发给第三方服务才能工作，只有在你主动触发时才会发送，且直接发往对应服务，我们不经手、不保存：

  • 快捷翻译：所框选的截图会发送到云端翻译服务。
  • 自备 Key 的翻译（DeepL、谷歌、微软、百度、腾讯、火山）：识别出的文字发送到你配置的服务商。
  • AI 视觉与云端抠图：图片发送到你自行配置 API Key 的服务商。
  • 图床上传：图片上传到你自己配置的存储服务。

这些服务如何处理数据，以各服务商自己的隐私政策为准。

4. 授权激活

输入激活码时，客户端会通过 HTTPS 向我们的授权服务器验证，之后也会定期联网确认授权状态。发送的信息只有：

  • 激活码；
  • 一个匿名的设备标识，以及设备名称，用于计算已激活的设备数、让你在换机时识别要解绑的设备；
  • 应用版本与系统版本。

我们不收集硬件序列号、MAC 地址、文件列表或任何截图内容。授权信息以加密形式保存在本机，只能在这台 Mac 上解密。

5. 购买

购买 Pro 时，我们会保存你填写的邮箱和订单信息（方案、金额、付款方式、订单备注码、付款时间），用于核对到账、发送激活码和处理售后。付款通过微信支付或支付宝完成，我们只能看到转账记录中的金额、备注等信息，接触不到你的银行卡号或支付密码。激活码邮件通过第三方邮件服务发送。

6. 检查更新

AuraSnap 检查更新时会访问 GitHub 上的发布页面获取最新版本信息，这个请求不包含你的个人信息。

7. 本网站

本网站（aurasnapapp.com）是静态网站，不使用广告或跟踪类 Cookie。网站托管服务商会留存常规的访问日志（如访问时间、IP 地址、浏览器类型），用于安全防护和保障可用性。价格页会在你的浏览器本地记住上次填写的邮箱，方便下次填写；首页会向 GitHub 查询最新版本号。

8. 你的控制权

  • 剪贴板历史可以在应用里随时清空，或关闭整个剪贴板模块。
  • 在「设置 › 关于」里可以解除本机的授权绑定，清除本机保存的授权信息。
  • 卸载 AuraSnap 并删除其数据目录，即可清除所有本地数据。
  • 如需查询、更正或删除我们保存的订单信息，请写信给我们。

9. 未成年人

本软件和服务不面向 14 周岁以下的未成年人。如果发现在未经监护人同意的情况下收集了未成年人的信息，我们会立即删除。

10. 政策更新

功能或法规变化时，我们可能更新本政策，并在本页注明更新日期；重大变更会在更新记录或网站上说明。
