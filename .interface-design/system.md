# AuraSnap Design System (v3.0 Master Edition)
*Single Source of Truth based on interface-design, taste-skill, and ui-ux-pro-max*

## 1. Design Philosophy
- **Anti-Slop**: Reject generic SaaS dark templates with boring 3-column cards. Create a living, breathing macOS artifact.
- **Direct Tactile Feedback**: Every button, slider, toggle, and canvas must respond to user input with spring physics and zero latency.
- **Authentic macOS Pro Aesthetic**: Precise system fonts, Apple Silicon color science, genuine macOS window controls, menu bars, traffic lights, and frosted glass.

## 2. Color Tokens (HSL Tailored)
- `bg-desktop`: `#06070b` (Deep Cosmic Black)
- `surface-base`: `#0b0e17`
- `surface-elevated`: `#111624`
- `surface-floating`: `rgba(17, 22, 36, 0.82)` with `backdrop-filter: blur(24px) saturate(190%)`
- `border-subtle`: `rgba(255, 255, 255, 0.08)`
- `border-focused`: `rgba(56, 189, 248, 0.45)`

- `rose-red`: `#f43f5e` (Red circle annotation & Stop)

## 3. Typography
- Display / UI: `'Plus Jakarta Sans'`, `'Noto Sans SC'`, `-apple-system`, `'SF Pro Display'`, sans-serif
- Code / Telemetry / Shortcuts: `'JetBrains Mono'`, `'SF Mono'`, monospace

## 4. Layout Rhythm (High Variance)
1. **Hero**: Interactive macOS Desktop Screen Simulator with active crosshair magnifier, snapping border, and floating ToolbarView.
2. **Feature Studio Playground**: 5 dynamic interactive tabs (Pin Window & Ghost, Screen Record & ⌘ Drag, Long Screenshot & 2D DP, AuraVision AI with Red Circle Focus, Toolbar Drag Reorder).
3. **Hardware Engine Specs**: Apple Silicon Accelerate math, Carbon C-API, Disk-backed memory curve.
4. **Live Keyboard Shortcut HUD**: Real-time keyboard-event lighting HUD.
5. **Architectural Benchmark**: Native Swift vs Electron transparent facts.
6. **Download & Build Hub**: Direct DMG download + GitHub links.
